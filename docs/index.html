Local and cloud models with Ollama

Add the Ollama presets to start Claude Code, Codex CLI or opencode with a local or Ollama cloud model. The agent keeps its tools: it still edits notes, runs commands and uses the shared skills.

  • Choose a model that supports tools and set a context length of 64k or more. Plain ollama run only chats.
  • You pick the model the first time; later launches reuse it.
  • Models ending in :cloud run on ollama.com.

Install

  1. In Obsidian, open Settings → Community plugins → Browse and search for “Agent Terminal” (once listed). Or download main.js, manifest.json and styles.css from the latest release into .obsidian/plugins/agent-terminal/.
  2. Enable the plugin and open a terminal from the ribbon or the command palette.
  3. Allow the one-time download of the terminal engine, then press 🤖 and pick an agent.

Good to know

  • Desktop only: Windows, macOS and Linux (x64, arm64), Obsidian 1.13.1 or later.
  • Install the agents themselves as usual; Agent Terminal starts them.
  • The only network request is the terminal engine (node-pty, 50–800 KB), downloaded once after you agree and verified with SHA-256. No data is collected.
  • Before your own CLAUDE.md or skills, or an edited ai-core.md, are replaced, a dialog lists them and asks first. Each one is kept as .bak, never deleted, and nothing changes if you cancel.
