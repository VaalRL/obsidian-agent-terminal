一鍵啟動

從按鈕、命令面板或快捷鍵啟動 agent、繼續上次的對話或跳過權限確認。只在 shell 等待輸入時才送出指令，不會打進執行中的程式。

✨

一份 AI 核心

筆記庫的規則只寫一次，自動連結成 CLAUDE.md、AGENTS.md、GEMINI.md，共用的 skills 也會出現在每個 agent 裡。

🧭

讓 agent 操作 Obsidian

透過 Obsidian 官方 CLI，agent 可以開啟今日筆記、切換檢視模式，或執行任何指令。

各 agent 的預設指令

每個預設都是可以自由修改的文字。選單預設包含 Claude Code 與 Antigravity CLI；Codex CLI 與 opencode 在設定頁按一下就能加入。

用 Ollama 跑本機或雲端模型

加入 Ollama 預設後，可以讓 Claude Code、Codex CLI 或 opencode 改用本機或 Ollama 雲端模型。agent 的工具照樣能用：一樣能修改筆記、執行指令、使用共用的 skills。

  • 請選支援工具（tools）的模型，context 長度設為 64k 以上。直接用 ollama run 只能聊天。
  • 第一次啟動時選模型，之後會沿用。
  • 名稱以 :cloud 結尾的模型在 ollama.com 上執行，內容會離開你的電腦。

讓 agent 操作 Obsidian

在設定 → 一般 → 命令列介面開啟並註冊後，執行 Bootstrap AI core。內附的 obsidian-cli skill 會教每個 agent 怎麼使用，並要求刪除、覆寫等動作前先詢問你。

請 agent…它會執行
開啟今日筆記obsidian daily
切換閱讀檢視obsidian command id=markdown:toggle-preview
切換原始碼模式obsidian command id=editor:toggle-source
執行任何指令obsidian command id=<id>

安裝

  1. 在 Obsidian 開啟設定 → 第三方外掛 → 瀏覽，搜尋「Agent Terminal」（上架後）。或從最新版本下載 main.js、manifest.json、styles.css，放到 .obsidian/plugins/agent-terminal/。
  2. 啟用外掛，從左側功能列或命令面板開啟終端機。
  3. 同意一次性下載終端機引擎，然後按 🤖 選擇 agent。

使用前須知

  • 僅支援桌面版：Windows、macOS、Linux（x64、arm64），Obsidian 1.13.1 以上。
  • agent 本身請照各自的方式安裝，Agent Terminal 負責啟動它們。
  • 唯一的網路連線是下載終端機引擎（node-pty，50–800 KB）：經你同意後只下載一次，並以 SHA-256 驗證。不收集任何資料。
  • 取代你自己的 CLAUDE.md、skills 或編輯過的 ai-core.md 之前，會先跳出視窗列出這些檔案並詢問你。每個檔案都會保留為 .bak，絕不刪除；按取消則不做任何變更。
